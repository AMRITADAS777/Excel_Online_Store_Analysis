# Excel_Online_Store_Analysis
This interactive dashboard was created in Microsoft Excel using Pivot Tables and Slicers. Slicers for Month, Channel, and Category are connected to all Pivot Tables, enabling dynamic filtering and real-time data analysis across the dashboard. Users can easily interact with the dashboard to view insights from different perspectives and make data-driven decisions.
Key Stages of the Project
Data Cleaning – Removed duplicates, handled missing values, corrected data inconsistencies, and standardized formats to ensure data accuracy.
Data Processing – Organized and transformed the raw data into a structured format suitable for analysis.
Age Grouping – Categorized customers into meaningful age groups to facilitate demographic analysis.
Month Extraction – Extracted month information from date fields to enable monthly trend analysis.
Data Analysis & Pivot Tables – Performed data analysis using Pivot Tables to summarize key metrics and identify trends, which were then used to build the interactive dashboard.
